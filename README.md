# 66일 퀘스트

하루를 시간 계층(L0 고정 → L1 필수 → L2 이벤트 → L3 희망)으로 쌓고, 정착시킬 행위 하나를 66일 동안 L1로 승격해 매일 실행하게 만드는 모바일 우선 PWA. 설계 근거는 "매일 실행 시스템 설계 v0" 문서.

## 실행

```bash
npm install
npm run dev        # 개발 서버
npm test           # 도메인·DB 단위 테스트 (Vitest + fake-indexeddb)
npm run build      # 타입 검사 + 프로덕션 빌드 (dist/)
npm run preview    # 빌드 결과를 로컬에서 확인 (서비스워커 포함)
```

하위 경로에 배포할 때는 `BASE_PATH=/저장소이름/ npm run build`.

## 구조

| 경로 | 내용 |
| --- | --- |
| `src/domain/types.ts` | 데이터 모델 (알림 모듈과 공유) |

## 규칙 요약

- 저장하는 사실은 하루 기록(최소/기본/최고)뿐이다. XP·콤보·실드는 매번 기록에서 다시 계산한다.
- XP: 그날 가장 높은 단계 하나 (최소 10, 기본 30, 최고 50). 누적 아님.
- 콤보: 최소 이상 연속일수. 실드 없음, 예외 0회.
- 기본 연속: 기본 이상 연속일수. 주(월~일)마다 실드 1개가 기본을 놓친 첫날을 자동으로 막는다. 안 쓰면 주가 끝날 때 +20 XP.
- 복귀 보너스: 기본을 놓친 다음 날 기본 이상이면 +20 XP. 실드를 쓴 날 다음 날도 해당.
- 오늘은 아직 끝나지 않은 날로 본다. 기록 전이면 콤보가 깨지지 않고, 최소만 했으면 실드를 아직 쓰지 않는다.
- 챕터 22일 × 3. 상한 20 / 30 / 45분. 챕터 첫날 기준 측정, 마지막 날 보스 측정.
- 66일째부터 SRBAI 4문항 점검. 평균 5점 이상이면 정착, 아니면 22일 연장 챕터.
- 레벨: 누적 XP 50·L·(L−1). 레벨이 오르면 카드가 해금된다.
